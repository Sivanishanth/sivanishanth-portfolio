Portfolio Website

A modern and responsive developer portfolio website built using React.js and Vite.
This portfolio showcases my projects, technical skills, resume, and contact information with a clean UI and interactive design.

🚀 Features
Modern Responsive UI
Hero Section
Skills Section with Icons
Project Showcase
Resume Download
Contact Form with EmailJS
Social Media Links
Hover Animations & Effects
Mobile Responsive Design
🛠️ Tech Stack
React.js
Vite
CSS3
React Icons
EmailJS
JavaScript (ES6+)
