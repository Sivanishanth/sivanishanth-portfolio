# Sivanishanth Portfolio Website

A modern and fully responsive personal portfolio website built using React.js and Vite.  
This portfolio highlights my technical skills, projects, resume, and contact information with a clean UI and interactive user experience.

---

## 🚀 Features

- Responsive Modern UI
- Hero Section
- Skills Section with Icons
- Project Showcase
- Resume Download
- Contact Form with EmailJS Integration
- Social Media Links
- Interactive Hover Effects
- Mobile Responsive Design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript (ES6+)
- CSS3

### Libraries & Tools
- React Icons
- EmailJS
- Git & GitHub

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Sivanishanth/sivanishanth-portfolio.git
```

Navigate to the project folder:

```bash
cd sivanishanth-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
